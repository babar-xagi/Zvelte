# ⚡ Example 03: Multi-Language Hybrid (Python + Zig + Web)

This example demonstrates the multi-language capabilities of Zvelte:
- Python server functions (`<script lang="python" context="server">`).
- Native Zig acceleration functions (`<script lang="zig" context="native">`).
- Browser Zig WebAssembly functions (`<script lang="zig" context="wasm">`).
- Client reactive state (`<state>`).

## 🚀 Running this Example

```bash
cd examples/03-hybrid-python-zig
zvelte dev
```

Visit [http://127.0.0.1:3003/](http://127.0.0.1:3003/) in your browser.
